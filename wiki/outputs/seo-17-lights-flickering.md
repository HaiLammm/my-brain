# 照明がちらつく・つかない原因とは？自分でできる確認方法と対処法

「天井の照明がちかちかと点滅して落ち着かない」「スイッチを入れても電気がつかない」と感じていませんか。照明のトラブルは一時的な電球切れのこともあれば、配線やスイッチ側の不具合が隠れていることもあります。

ちらつきを放置していると、目への負担だけでなく、機器の発熱や火災リスクにつながるケースもあります。早めに原因を切り分けて、自分で対応できる範囲か業者に頼むべきかを判断することが大切です。

この記事では、照明がちらつく・つかないときにここを順番に確認してほしいポイントと、考えられる原因、業者へ相談したほうがよいタイミングについて解説します。

## 1. 照明がちらつく・つかないときに順番に確認したいこと

照明のトラブルの多くは、電球切れや差し込みのゆるみといった簡単な原因で発生します。難しい作業をする前に、安全に確認できるところから順番にチェックしましょう。

確認の際は、必ず照明のスイッチを切り、電球の交換時は本体が冷めてから行ってください。

### 1.1. 電球・蛍光灯本体の状態を確認する

最初に確認したいのは電球や蛍光灯そのものの状態です。寿命が近づくと、ちらつきや明るさのムラとして症状が出やすくなります。

- 電球が黒ずんでいないか、フィラメントが切れていないか確認する
　➞ 黒ずみがあれば寿命が近い／切れている可能性
- 電球がソケットにしっかりはまっているか、緩んでいないか確認する
　➞ 軽く回して固定し直す（熱い状態では触らない）
- 蛍光灯の場合は両端の黒ずみ、点灯管（グロー球）の寿命も確認する
- 別の同型・同W数の電球に交換すると改善するか試す

電球交換だけで直ることはとても多いケースです。なお、種類の違うW数や規格の電球を使うと発熱や故障の原因になるため、必ず器具の仕様に合うものを使ってください。

### 1.2. スイッチとリモコンの動作を確認する

電球側に問題がなければ、スイッチやリモコンの操作系を確認します。

- 壁スイッチを「カチッ」と確実に切り替えてみる
　➞ 半押しの状態だと接触不良で点滅することがある
- リモコン式照明の場合は電池を新品に交換してから操作する
- 調光機能つきの場合は、明るさを最大にして点灯するか試す
　➞ 調光側の不具合でちらつくことがある
- スイッチを操作したときに「ジー」「パチパチ」と音がしないか確認する

調光対応していない電球を調光スイッチで使っていると、ちらつきが出る場合もあります。器具とのマッチも見直すポイントです。

### 1.3. ブレーカーと他の照明の状態をチェックする

1つの部屋だけでなく、他の部屋でも照明が不安定になっていないかも確認してみましょう。

- 分電盤を開いて、対象回路のブレーカーが正常に上がっているか確認する
- 他の部屋でも照明がちらついていないか確認する
　➞ 家全体でちらつく場合は屋内配線や受電側の問題の可能性
- 大型家電（エアコン、電子レンジなど）を使ったときだけちらつくか観察する
　➞ 電圧降下による一時的なちらつきの可能性
- 雷雨や強風の後から症状が出ていないか思い返す

複数の部屋で同時に症状が出る場合や、家電を使うたびにちらつく場合は、家全体の電気容量や配線が関係していることがあるため次の章を確認してください。

## 2. それでも改善しないときに考えられる原因

電球交換やスイッチ操作で改善しない場合は、器具内部や配線側の問題が考えられます。ここでは自分で対処できない領域の主な原因を紹介します。

### 2.1. 安定器や電源回路の劣化

蛍光灯やLED照明の中には、「安定器」や「電源回路（ドライバ）」と呼ばれる部品が入っています。これらが劣化すると、電気の流れが不安定になり、ちらつきや突然消える症状を引き起こします。

- 設置から10年以上経過している照明器具
- スイッチを入れてから点灯するまで時間がかかる
- 「ジー」「ブーン」といううなり音が以前より大きくなった

安定器の交換は器具内部を開ける必要があるため、原則として専門業者の作業範囲です。

### 2.2. 配線・結線部の接触不良

天井裏や壁の中の配線、シーリングローゼット（天井の取り付け金具）の結線部分がゆるんだり、酸化したりすると、照明への電気の流れが不安定になります。

- 照明器具を回したり叩いたりすると一時的に直る
- 取り付け部分から焦げたようなにおいがする
- リフォーム後や引っ越し後から症状が出始めた

このような状態は、内部で発熱や火花が起きている可能性があり、火災のリスクにつながります。

### 2.3. LED器具側の電子部品トラブル

LED照明はコンデンサやドライバICなど多くの電子部品で構成されています。これらが故障すると、メーカー保証外では基本的に器具ごと交換になります。

- 購入してから数年以内なのに頻繁にちらつく
- 一部のLED粒だけ点灯しない
- 点灯後しばらくすると勝手に消える

メーカー保証期間内であれば、まずは購入店やメーカーサポートに相談するのも有効です。

## 3. こんなときは早めの相談を

電球やスイッチを見直しても改善しない場合、また次のような状況が見られる場合は、無理に使い続けず早めに専門業者へ相談しましょう。

| 自分で対処しやすいケース | 業者へ相談したいケース |
| --- | --- |
| 電球・蛍光灯の寿命切れ | 照明から焦げたにおいがする |
| ソケットの差し込み甘さ | 取り付け部分が変色している |
| リモコンの電池切れ | 「ジー」「パチパチ」と異音が続く |
| 調光スイッチとの相性 | 家全体で照明が不安定 |
| 一時的な電圧降下 | 設置から10年以上で症状が悪化 |
| ― | 触ると本体が異常に熱い |

特に焦げたにおいや異常な発熱、火花が見られた場合は、火災のリスクが非常に高い状態です。すぐに該当回路のブレーカーを下ろし、使用を止めてから連絡してください。

また、天井裏の配線や器具内部の修理は電気工事士の資格が必要な作業です。自分で器具を外したり、配線を触ったりするのは絶対に避けましょう。
