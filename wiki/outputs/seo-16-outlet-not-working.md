# コンセントが使えない原因とは？自分でできる確認方法と対処法

「いつも使っているコンセントに差したのに家電が動かない」「特定の部屋だけ電気が来ていない気がする」——そんな状況になると、停電なのか故障なのか判断がつかず不安になります。

コンセントが使えなくなる原因は、ブレーカーが落ちているケース、家電側の不具合、コンセント内部の劣化など複数あります。なかには差し直しやブレーカー確認で解決するものもあれば、内部の配線異常で火災リスクにつながるケースもあるため、順番に確認することが大切です。

この記事では、コンセントが使えないときにここを順番に確認してほしいポイントと、考えられる原因、業者へ相談したほうがよいタイミングについて解説します。

## 1. コンセントが使えないときに順番に確認したいこと

コンセントが使えなくなったとき、いきなり「故障だ」と決めつける前に、簡単な確認で解決するケースは少なくありません。ここでは安全に試せる順番で確認ポイントを整理します。

確認する前に、コンセントから差し込んでいた家電のプラグはいったん抜いておきましょう。

### 1.1. 家電側に問題がないかを切り分ける

「コンセントが悪いのか、家電が悪いのか」を切り分けるのが最初のステップです。コンセント自体には問題がないのに、家電側の故障で動かないだけというケースもあります。

- 別のコンセント（隣の部屋など、確実に使える場所）に同じ家電を差してみる
　➞ 動けば家電は正常、コンセントが原因の可能性が高い
- 同じコンセントに別の家電（スマホの充電器など小さなもの）を差してみる
　➞ 動けばコンセントは正常、最初の家電側に問題がある可能性
- 延長コードを介して使っていた場合は、延長コード自体の故障も確認する

家電とコンセントを入れ替えて試すだけで、原因のどちら側か判断しやすくなります。

### 1.2. ブレーカーが落ちていないか確認する

特定の部屋やエリアのコンセントだけ使えない場合は、分電盤のブレーカーが落ちている可能性があります。

- 分電盤を開けて、安全ブレーカー（小さいスイッチ）を一つずつ確認する
　➞ 一つだけ「切」になっている場合は、その回路が落ちている状態
- 漏電ブレーカー（中央の少し大きいスイッチ）が落ちている場合は、漏電している可能性がある
- ブレーカーを上げ直しても、すぐにまた落ちる場合は無理に何度も入れ直さない

ブレーカーが落ちていたら、コンセントに差していた家電をすべて抜いてから上げ直してみましょう。上げてもまた落ちる場合は、漏電や過電流の可能性があり、自分での対処は危険です。

### 1.3. コンセントまわりと差し込みを見直す

家電・ブレーカーに問題がない場合は、コンセント本体まわりを目で見て確認します。

- プラグがしっかり奥まで差し込まれているか確認する
　➞ 差し込みが甘いと通電しないことがある
- コンセントの差し込み口がゆるくなっていないか確認する
　➞ プラグを差してもすぐ抜けてしまう状態は内部のバネが劣化している可能性
- コンセント周辺に焦げ跡や黒ずみ、変色がないか確認する
　➞ 焦げ跡や異臭がある場合はすぐに使用を止める

差し直しでも反応がなく、見た目に異常がなければ、内部のトラブルが疑われるため次の章を確認してください。なお、焦げ跡や異臭がある場合は3章のSTOPサインなので、無理に使い続けないことが大切です。

## 2. それでも改善しないときに考えられる原因

家電・ブレーカー・差し込みのすべてに問題がないのにコンセントが使えない場合、内部や配線の劣化が関係していることがあります。ここでは自分で対処できない領域の原因を紹介します。

### 2.1. コンセント内部の接点劣化・焼け

コンセントは長年使ううちに、内部の金属接点が徐々に摩耗・劣化していきます。差し込んでも電気がうまく流れず、家電が動かない状態になることがあります。

特に以下のような環境では、内部劣化が進みやすいといわれます。

- 設置から15〜20年以上経過している
- 大きな電流を流す家電（電子レンジ、ドライヤー、エアコンなど）を頻繁に使ってきた
- 過去にプラグが抜けかけたまま使い続けたことがある

接点劣化が進むと、通電不良だけでなく異常発熱や火災のリスクにもつながります。

### 2.2. 屋内配線の断線・接触不良

コンセントの奥には屋内配線がつながっています。配線そのものが古くなって断線したり、結線部分の接触が悪くなったりすると、コンセントに電気が届かなくなります。

- リフォームや家具配置を変えた後から使えなくなった
- 壁の中で工事跡や水漏れがある近くのコンセント
- 雷が落ちた後から使えなくなった

壁の中の配線は目で確認できず、自分での修理もできない領域です。

### 2.3. アース不良や漏電の発生

水まわりの近くで使うコンセント（キッチン、洗面所、洗濯機、エアコン用など）では、アース不良や漏電が原因で電気が来なくなっていることがあります。

漏電ブレーカーが作動した結果としてコンセントが使えない場合、見た目では分かりにくいケースもあります。

- 湿気の多い場所のコンセントで急に使えなくなった
- 雨の日や濡れた後に使えなくなった
- ブレーカーを上げてもすぐに落ちる

漏電は感電や火災のリスクがあるため、原因の特定と修理は専門業者に任せるのが安全です。

## 3. こんなときは早めの相談を

家電の入れ替えやブレーカー確認、差し込みの見直しを試しても改善しない場合や、次のような状況が見られる場合は、無理に使い続けず早めに専門業者へ相談しましょう。

| 自分で対処しやすいケース | 業者へ相談したいケース |
| --- | --- |
| 家電側の故障で動かない | 焦げ跡や黒ずみ、変色がある |
| プラグの差し込み不足 | 異臭・発熱・火花が出ている |
| ブレーカーが落ちただけ | 上げてもすぐブレーカーが落ちる |
| 延長コードの不具合 | 壁の中の配線が原因と思われる |
| 一時的な過電流 | 水まわりで漏電の疑いがある |
| ― | 15〜20年以上同じコンセントを使っている |

特に焦げ跡・異臭・発熱・火花のいずれかが見られた場合は、感電や火災のリスクが非常に高い状態です。使用を止めて、その回路のブレーカーを下ろしてから連絡してください。

また、コンセントの内部部品交換や屋内配線の修理は、電気工事士の資格がないと法律上行うことができません。自分で分解したり配線をいじったりすることは絶対に避けましょう。
