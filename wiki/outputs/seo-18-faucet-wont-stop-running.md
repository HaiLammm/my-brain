# 蛇口から水が止まらない原因とは？自分でできる確認方法と対処法

「キッチンの蛇口をしっかり閉めたのにポタポタ水が落ちる」「洗面所のレバーを下ろしても水が止まらない」——蛇口から水が止まらないと、水道代が気になるだけでなく、放置すれば水浸しや床下漏水につながることもあります。

蛇口の水漏れは、内部のパッキンやカートリッジの劣化など、比較的シンプルな原因で起きていることが多くあります。ただし、無理にハンドルを締めすぎたり分解したりすると症状が悪化することもあるため、順番に確認することが大切です。

この記事では、キッチン・洗面の蛇口から水が止まらないときにここを順番に確認してほしいポイントと、考えられる原因、業者へ相談したほうがよいタイミングについて解説します。

## 1. 蛇口から水が止まらないときに順番に確認したいこと

蛇口からの水漏れに気づいたら、放っておかずに被害を広げない対応から始めるのが鉄則です。安全に確認できる範囲から順番にチェックしましょう。

### 1.1. まずは止水栓を閉めて被害を広げない

漏れの程度が大きい場合や、水浸しになりそうな場合は、最初に止水栓を閉めて水を止めることが最優先です。

- シンク下や洗面台下の収納を開けて、給水管に取り付けられた止水栓を探す
　➞ ハンドル式（蝶ネジ）かマイナスドライバーで回すタイプが一般的
- 止水栓を時計回りに回して閉める（強く締めすぎない）
- 止水栓が見当たらない、または固くて回らない場合は、家全体の元栓（メーター付近）を閉める

止水栓を閉めれば水は止まるので、慌てて分解せずに次のステップへ進めます。なお、長年触っていない止水栓は固着していることがあるため、無理に力をかけると配管を傷める原因になります。回らないときは元栓側を使ってください。

### 1.2. 水漏れの位置と症状を見極める

蛇口の「どこから」「どんな出方で」水が漏れているかによって、原因がある程度絞り込めます。

- 吐水口（水が出る先端）からポタポタ落ちる
　➞ 内部パッキンやカートリッジの劣化が多い
- ハンドルの根元から水がにじむ
　➞ ハンドル側のパッキン劣化
- レバーや本体と台座の境目から水が漏れる
　➞ 取り付け部のパッキンやシール不良
- 給水管との接続部から漏れている
　➞ ナットのゆるみや配管側のパッキン劣化

漏れの位置をスマホで写真に撮っておくと、後で業者に相談する際にも状況が伝えやすくなります。

### 1.3. ハンドルやレバーの動きを確認する

ハンドルを締めても水が止まらない場合、ハンドル側の動作も見直してみましょう。

- 二ハンドル式（お湯・水で別ハンドル）の場合、両方を最後まで締めても止まらないか確認する
- レバー式の場合、レバーを左右に動かしながら一番下まで下ろせるか確認する
　➞ 引っかかりや「カチッ」と止まらない感覚があれば内部不良の可能性
- ハンドルを強く締めすぎていないか確認する
　➞ 締めすぎは内部パッキンを傷める原因になる

ハンドルを「グッ」と力を入れて締めても止まらない場合は、内部部品の劣化が進んでいる可能性が高いため、次の章を確認してください。

## 2. それでも改善しないときに考えられる原因

止水栓で被害を防いだあとも、根本の原因を直さない限り使用は続けられません。ここでは自分では対処しにくい主な原因を紹介します。

### 2.1. パッキン・コマの経年劣化

蛇口の中には、水を止めるためのゴムパッキンや「コマ」と呼ばれる部品が入っています。これらは消耗品で、5〜10年程度で硬化・ひび割れが進みます。

- 設置から10年近く経っている蛇口
- 以前は強く締めれば止まっていたが、最近は止まりにくくなった
- ポタポタとした少量の水漏れが続く

パッキン交換自体は部品代も安く、DIYで行う人もいますが、蛇口のメーカー・型番に合う部品を正確に選び、適切な順番で分解・組み立てる必要があります。誤った部品や締め付けで悪化させるケースも少なくありません。

### 2.2. シングルレバーのカートリッジ不良

レバー1本で水量と温度を調節するシングルレバー混合栓では、内部の「カートリッジ」と呼ばれる部品が水流を制御しています。これが摩耗・故障すると、レバーを下げても水が止まらなくなります。

- レバーの操作感が以前より重い、または軽すぎる
- 水とお湯の切り替えがスムーズに行かない
- 漏れる位置がレバーの根元あたり

カートリッジは蛇口本体ごとに専用品で、互換性のないものを取り付けると水漏れや破損の原因になります。

### 2.3. 水栓本体の摩耗・サビ

長年使用した水栓は、本体内部の金属部や接続部にサビ・腐食が発生していることがあります。

- 設置から15年以上経過している
- 水道水に含まれる成分で内部に白い結晶や緑青がついている
- パッキン交換しても再発を繰り返す

このような状態では、部品交換ではなく水栓本体ごとの交換が必要になるケースが多くなります。

## 3. こんなときは早めの相談を

止水栓で水を止めて応急処置をしたあとも、根本の修理は早めに済ませたほうが安心です。次のような状況が見られる場合は、無理に使い続けず専門業者へ相談しましょう。

| 自分で対処しやすいケース | 業者へ相談したいケース |
| --- | --- |
| ハンドルの締め忘れ | 止水栓を閉めても漏れが止まらない |
| 軽いパッキン交換（型番が分かる） | レバーや本体根元から大量に漏れる |
| 給水管ナットの軽い増し締め | シンク下や床が常に濡れている |
| ― | 設置から15年以上の蛇口 |
| ― | 自分で分解したが組み立てられない |
| ― | カビ臭・カビの広がりが気になる |

特に止水栓を閉めても漏れが止まらない、シンク下や床が常に濡れている場合は、配管側のトラブルや床下漏水につながっている可能性があります。そのまま放置すると、階下漏水や床材の腐食、カビ被害につながるため早急な対応が必要です。

また、慣れていない方が分解作業を行うと、部品の紛失や逆組み付けで状態が悪化するケースがあります。型番が特定できない、部品が手に入らない場合も無理せず業者を頼るのが安全です。
