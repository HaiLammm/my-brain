## Definition

FastAPI là web framework Python hiệu năng cao cho xây dựng API endpoints. Trong kiến trúc dịch ngữ ngữ nghĩa-hình học, FastAPI expose các endpoint consultation và geometric translation cho frontend Adaptive Canvas.
