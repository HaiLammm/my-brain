## Definition

Keras là high-level Deep Learning API giúp xây dựng và huấn luyện neural networks một cách đơn giản và trực quan. TensorFlow tích hợp sẵn tf.keras. Hỗ trợ ba kiểu API: Sequential (xếp tầng đơn giản), Functional (đa đầu vào/đầu ra), Subclassing (tùy biến hoàn toàn).
