## Definition

Confusion Matrix là bảng mô tả hiệu năng của mô hình classification bằng cách đối chiếu nhãn dự đoán với nhãn thực tế. Gồm 4 ô: True Positive, False Positive, True Negative, False Negative. Từ đó tính được accuracy, precision, recall, F1-score.
