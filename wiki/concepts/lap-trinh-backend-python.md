## Definition

Lập trình backend Python là phát triển phần máy chủ của ứng dụng sử dụng ngôn ngữ Python, bao gồm xây dựng API, xử lý logic nghiệp vụ và tích hợp cơ sở dữ liệu. Trong bối cảnh tuyển dụng EAERA, yêu cầu thành thạo Python cho backend là kỹ năng cốt lõi bắt buộc.

## Variants

- **Python framework**: Django, Flask, FastAPI — các framework phổ biến cho backend Python.
- **Scripting Python**: Dùng Python cho tự động hóa hạ tầng và công cụ hỗ trợ.
