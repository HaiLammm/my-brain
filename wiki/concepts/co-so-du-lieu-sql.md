## Definition

Cơ sở dữ liệu SQL là nhóm hệ quản trị dữ liệu quan hệ và ngôn ngữ truy vấn đi kèm, dùng để lưu trữ, truy xuất và quản lý dữ liệu có cấu trúc. Trong JD Thái Bình, yêu cầu PostgreSQL, MySQL và MSSQL cho thấy ứng viên cần đủ chắc về mô hình dữ liệu quan hệ trong môi trường doanh nghiệp.
