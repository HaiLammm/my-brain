## HTML Structure

No standalone HTML — these are JS modules imported by page HTML files. Each module exports a render function that creates DOM elements and appends to the given container.

`shared/design-tokens.css` is a `<link>` included in every page's `<head>`.

---

## Tailwind Classes

Using Tailwind CDN via `<script src="https://cdn.tailwindcss.com">` in page HTML. Components use Tailwind utility classes inline. Design tokens are CSS custom properties referenced where Tailwind doesn't cover (e.g., specific hex colors via `style` attributes or Tailwind config extend).

---

## JavaScript Requirements

- Each component is a standalone ES module (`export function render...`)
- Components create DOM elements programmatically (no template literals with innerHTML for security)
- All components are stateless — state managed by the page that imports them
- Lucide Icons loaded via CDN: `https://unpkg.com/lucide@latest`

---

## Demo Data Requirements

Components receive data via function parameters. Demo data from `data/demo-data.json` is loaded by the page, not by components.
