## Purpose

Create the hero banner with Da Nang imagery, tagline, search bar, and quick filter chips. This is the first thing users see — must convey "this is for Japanese people in Da Nang" immediately.

| Object | Type | Detail |
|--------|------|--------|
| Hero container | div | Full-width, min-height 420px, gradient bg placeholder, relative |
| Overlay | div | Absolute, dark gradient overlay for text readability |
| Tagline | h1 | "Everything about Da Nang, right here." — white, 40px, bold, centered |
| Subtitle | p | "A Da Nang guide built on senpai experiences" — white/80%, 18px, centered |

## States

- Default: hero with gradient, white text, search empty
- Search focused: teal ring
- Chip hover: bg-accent (#2EC4B6), text white, transition 200ms
