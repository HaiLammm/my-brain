## Purpose

Create the responsive page scaffold for the Senpai Article/Guide page (03.1-senpai-article-guide.html). Includes design tokens CSS, bottom tab navigation, translation FAB, Google Fonts, and demo data loading. This shell serves as the foundation for all subsequent sections.

**Note:** Reuse design-tokens.css pattern from Scenario 01 prototype, extended with additional tokens needed for Scenario 03 (bottom tab nav, FAB, responsive breakpoints).

## Objects

### O19: Bottom Tab Navigation

| Element | Detail |
|---------|--------|
| Container | Fixed bottom, full-width, white bg, top border 1px #E5E7EB, height 64px, z-50 |
| Layout | 5 equal tabs, flexbox, center-aligned |
| Tab icons | Lucide: Home, Search, MessageCircle, Tag, User — 24px |
| Tab labels | "Home", "Search", "Community", "Deals", "Profile" — 11px |
| Default state | Icon + label gray (#6B7280) |
| Active state | Icon + label Teal (#2EC4B6) — no tab active on article page |
| Tap | Placeholder navigation (console.log) |
| Shadow | `0 -2px 8px rgba(0,0,0,0.06)` (shadow-sticky from tokens) |

**Responsive:**
- Mobile (< 768px): Visible, fixed bottom
- Tablet (768-1024px): Hidden — replaced by top nav
- Desktop (> 1024px): Hidden — replaced by top nav

## CSS Requirements

Extend design-tokens.css with:
```css
--shadow-sticky: 0 -2px 8px rgba(0,0,0,0.06);
--shadow-fab: 0 4px 12px rgba(0,0,0,0.15);
--breakpoint-sm: 640px;
--breakpoint-md: 768px;
--breakpoint-lg: 1024px;
--breakpoint-xl: 1280px;
```

## JavaScript Requirements

### shared/app.js

| Function | Purpose |
|----------|---------|
| `loadDemoData()` | Fetch and parse data/demo-data.json, store in window.demoData |
| `renderBottomTabNav(containerId)` | Render 5-tab bottom nav with icons (Lucide) |
| `renderTranslationFAB(containerId)` | Render coral FAB with mic icon |
| `initPage()` | Load demo data, render shell components, initialize Lucide icons |

All functions called on DOMContentLoaded.
