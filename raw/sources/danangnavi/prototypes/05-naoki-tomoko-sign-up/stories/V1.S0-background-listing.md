# Story: V1.S0 — Background Listing Page

**View:** V1 — Sign Up / Login
**Section:** S0
**Spec:** 05.1-sign-up-login.md (context: modal overlay on listing detail)

---

## Purpose

Create a static listing detail page that serves as visual context behind the signup modal. Non-interactive — exists only to show Naoki was browsing an apartment when the signup prompt appeared.

## Objects

| ID | Element | Type | Detail |
|----|---------|------|--------|
| 18 | Background Listing Page | Static page | Simulated apartment listing detail |

## HTML Structure

```
body
├── .page-container (max-width: 800px, centered)
│   ├── .listing-header
│   │   └── .listing-hero-image (16:9, placeholder photo)
│   ├── .listing-body
│   │   ├── .listing-title-row
│   │   │   ├── h1.listing-title ("Modern 1BR Apartment near Dragon Bridge")
```

## Design Tokens

- Background: `--color-bg` (#FAFAF8)
- Page container: `--color-surface` (#FFFFFF), `--shadow-card`
- Title: `--text-h2` (1.5rem), `--color-text-primary`
- Price VND: `--text-h3` (1.25rem), `--color-secondary` (#FF6B4A), bold
- Price JPY: `--text-caption`, `--color-text-secondary`
- Rating star: `--color-warning` (#F2994A)
- Senpai badge: `--color-accent` (#2EC4B6), small pill
- Save button: outline heart, `--color-text-secondary`, 24px
- Bottom nav: same as other prototypes
- Feature pills: `--color-bg`, `--radius-full`, `--text-caption`

## Demo Data

From `data/demo-data.json` → `triggerListing`:
- title: "Modern 1BR Apartment near Dragon Bridge"
- price: 8,000,000 VND → ¥46,000

## JavaScript

- Minimal: load demo data, render listing content
- Save button click → no action (modal is already shown on page load)
- No interactivity needed on listing itself
