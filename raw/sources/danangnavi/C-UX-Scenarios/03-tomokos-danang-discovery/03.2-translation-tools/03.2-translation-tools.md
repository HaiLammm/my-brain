## Overview

| Field | Detail |
|---|---|
| **Page Purpose** | Enable Tomoko to use voice translation to order food at a restaurant, ask about spice level, and confirm the bill — all without speaking Vietnamese. |
| **Entry Points** | Bottom tab nav "翻訳" (Translate) icon; floating translate button on any page; deep link from restaurant listing; link from senpai guide article. |
| **User Mental State** | |
| *Trigger* | She is sitting at the restaurant, the menu is entirely in Vietnamese, and the server is approaching. She needs to communicate NOW. |
| *Hope* | "I can order confidently without embarrassing myself or getting something I can't eat." |
| *Worry* | "What if the translation is wrong and I get super spicy food? What if the server doesn't understand the robot voice?" |
| **Main User Goal** | Successfully order a meal, specify dietary preferences (no spice), and ask for the bill — all through her phone. |
| **Business Goal** | Demonstrate indispensable utility of DaNangNavi during real moments of need; increase session depth and daily active usage; collect phrase usage data to improve translation quality. |
| **URL / Route** | `/tools/translate` |

## Journey Context

Tomoko found a local restaurant through a senpai guide article (Page 03.1). She is now seated, Day 2 of her 5-day vacation, near My Khe Beach. The menu has no Japanese or English. She opens the translation tool from the floating button she noticed earlier. After the meal she will recall the coupon she saw on the senpai guide and navigate to the Deals page (Page 03.3).

## On-Page Interactions

| Interaction | Trigger | Result | Animation / Feedback |
|---|---|---|---|
| Start voice input | Tap mic button | Begin speech recognition, mic button pulses | Coral pulse ring expands and contracts with audio amplitude. |
| Stop voice input | Tap mic button again or silence detected | Process speech, show Japanese text, then Vietnamese translation | Bubble slides in from left (JP) then right (VN), `300ms` ease-out. |
| Play audio | Tap speaker icon on Vietnamese bubble | Play Vietnamese audio aloud | Speaker icon animates with sound waves. Button shows loading spinner if audio is generating. |
| Use quick phrase | Tap phrase chip | Instantly show translation pair in conversation area + auto-play audio | Chip briefly fills Coral, translation pair appears with slide animation. |
| Show to staff | Tap "スタッフに見せる" | Vietnamese text displays full-screen, large font, high contrast | Fade to full-screen white bg, Vietnamese text centered `36px` bold, with "戻る (Back)" at top. |
| Open camera translate | Tap camera button | Camera viewfinder opens with live text detection | Slide-up transition `400ms`. |
| Swap language direction | Tap ↔ icon | Switch from JA→VI to VI→JA (for understanding server responses) | Flags swap with flip animation `200ms`. |
| Scroll conversation | Swipe up in conversation area | See previous translation exchanges | Standard scroll, sticky language pair indicator at top. |
| Expand FAB bottom sheet | Swipe up on mini translation panel | Full translation page slides up | Sheet expands from `60vh` to full screen, `300ms`. |

## Responsive Behavior

| Breakpoint | Layout Adjustment |
|---|---|
| **Mobile (< 768px)** | Default layout. Mic button centered and prominent `80px`. Quick phrases in single horizontal scroll row. Conversation area takes remaining vertical space. Bottom sheet mode for FAB access. |
| **Tablet (768px - 1024px)** | Mic button area and conversation area side by side in landscape. Quick phrases show 2 rows. Camera viewfinder uses full tablet screen with larger overlay labels. |
| **Desktop (> 1024px)** | Two-column layout: left column is conversation history (scrollable), right column has mic button + quick phrases + camera trigger. Floating button becomes a fixed sidebar icon. Full phrasebook visible as right sidebar panel when in phrasebook mode. |
