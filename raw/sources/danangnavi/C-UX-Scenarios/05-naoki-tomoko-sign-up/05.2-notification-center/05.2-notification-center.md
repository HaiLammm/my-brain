# 05.2 Notification Center

**Scenario:** 05: Naoki & Tomoko Sign Up
**Page Number:** 05.2
**Created:** 2026-04-07
**Method:** Whiteport Design Studio (WDS)

---

## Overview

**Page Purpose:** Set notification preferences so Naoki gets relevant updates on listings, community replies, deals, and events — without being overwhelmed by noise.

**Entry Points:**
- Auto-redirect from Sign Up modal (05.1) after account creation (primary)
- Settings menu "通知設定" (Notification Settings)
- Direct URL /settings/notifications

**User Mental State:**
- **Trigger:** Account just created, apartment was auto-saved, feeling good about the quick signup
- **Hope:** "I want to know when new apartments or deals pop up, but I don't want spam"
- **Worry:** "If I turn on notifications, will I get bombarded with messages?"

**Main User Goal:** Quickly configure useful notifications and get back to browsing the apartment listing he saved

**Business Goal:** Maximize notification opt-in rates with sensible defaults, establish a re-engagement channel (LINE/push) for retention

**URL/Route:** `/settings/notifications` (or modal continuation from 05.1 depending on implementation)

### Section 2: Notification Categories

| Element | Detail |
|---------|--------|
| Layout | Vertical list of toggle cards |
| Section label | "通知カテゴリ" (Notification Categories) |

**Category Toggle Cards:**

| Category | Japanese Label | Description | Default | Icon |
|----------|---------------|-------------|---------|------|
| New listings in area | 新着物件 | あなたのエリアの新しい物件 (New listings in your area) | ON | House icon |
| Community replies | コミュニティ返信 | 質問への返信や@メンション (Replies to your posts and @mentions) | ON | Chat bubble icon |
| Weekly deals | お得情報 | 週1回のお得な情報まとめ (Weekly deals digest) | ON | Tag/sale icon |
| Events near you | イベント | 近くのイベント情報 (Events happening near you) | OFF | Calendar icon |

| Design Detail | Value |
|---------------|-------|
| Toggle style | iOS-style toggle switch, teal (#2EC4B6) when ON, gray when OFF |
| Card style | White card with left icon, label, description, and toggle aligned right |
| Tap area | Entire card row is tappable to toggle (not just the switch) |
| Design rationale | Sensible defaults (3 ON, 1 OFF) maximize opt-in while respecting the "events" category which may feel less urgent for a newcomer. Users who want everything can toggle events ON; users who want less can toggle off. |

| Design Detail | Value |

### Section 5: Save Actions

| Element | Detail |
|---------|--------|
| Primary CTA | "設定を保存" (Save Settings) — Coral (#FF6B4A) button, full-width on mobile |
| Tap behavior | Saves preferences, shows brief success toast "設定を保存しました ✓" (Settings saved), then redirects to the saved listing |

| Design rationale | Both paths lead back to the listing Naoki wanted. "Save" gives control; "Skip" gives speed. Either way, notifications are configured with reasonable defaults. |

## On-Page Interactions

| Interaction | Type | Detail |
|-------------|------|--------|
| Category toggle tap | On-page | Toggles individual notification category ON/OFF |
| Card row tap | On-page | Same as toggle — full row is tappable |
| Frequency segment select | On-page | Switches between instant/daily/weekly delivery |
| Delivery channel toggles | On-page | Enable/disable LINE, push, email channels |
| Push notification toggle ON | Browser prompt | Triggers browser notification permission dialog |
| "設定を保存" tap | Navigation | Saves settings, toast confirmation, redirects to saved listing |
| "あとで設定する" tap | Navigation | Applies defaults, redirects to saved listing |
| Back/close | Navigation | Returns to saved listing with default notification settings applied |
