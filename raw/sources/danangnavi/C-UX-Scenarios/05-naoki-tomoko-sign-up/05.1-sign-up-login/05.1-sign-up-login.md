# 05.1 Sign Up / Login

**Scenario:** 05: Naoki & Tomoko Sign Up
**Page Number:** 05.1
**Created:** 2026-04-07
**Method:** Whiteport Design Studio (WDS)

---

## Overview

**Page Purpose:** Create an account via LINE login with minimal friction — get back to the content as fast as possible. The signup must feel like a 5-second detour, not a roadblock.

**Entry Points:**
- "Save to favorites" tap on any listing detail page (primary)
- "Post a question" in Community Hub
- Any feature requiring authentication (bookmark, review, booking)

**User Mental State:**
- **Trigger:** Tapped "Save to favorites" on an apartment listing he wants to come back to — a signup modal appeared
- **Hope:** "Let me just sign up quickly so I can save this apartment and keep browsing"
- **Worry:** "Another long registration form asking for unnecessary personal information"

**Main User Goal:** Create an account in under 10 seconds and have the apartment automatically saved

**Business Goal:** Convert engaged browsers into registered users with minimal abandonment, capture LINE connection for future notifications and re-engagement

**URL/Route:** Modal overlay on current page (no URL change — preserves scroll position and context)

---

## Journey Context

This is **page 1 of 2** in the "Naoki & Tomoko Sign Up" scenario.

**Next Page:** Notification Center (05.2)

**Scenario Goal:** Naoki creates an account effortlessly and sets up notifications so he never misses relevant updates.

**Cross-Scenario Context:** This modal can be triggered from any scenario (01 Naoki's First Week, 03 Tomoko's Discovery, etc.) whenever an unauthenticated user attempts a registered-only action.

| Element | Detail |

### Section 3: LINE Login Button

| Element | Detail |
|---------|--------|

| Button color | LINE green (#06C755) |

## On-Page Interactions

| Interaction | Type | Detail |
|-------------|------|--------|
| Modal appearance | On-page (overlay) | Triggered by auth-required action, no page navigation |
| "×" close button | On-page | Dismisses modal, returns to browsing, action not completed |
| Backdrop tap | On-page | Same as close — dismisses modal |
| LINE login tap | External + return | Opens LINE auth flow, returns to DaNangNavi on completion |
| "メールで登録" accordion | On-page | Expands email/password form within modal |
| Email form submit | On-page | Validates, creates account, shows success state |
| Success auto-redirect | Navigation | → 05.2 Notification Center (after 1.5s delay) |
| Terms/Privacy links | Navigation (new tab) | Opens legal pages in new tab, modal stays open |

## Responsive Behavior

| Breakpoint | Changes |
|------------|---------|
| Mobile | Modal becomes bottom sheet (slides up from bottom, border-radius top only). Full-width. LINE button and social proof prominent. Email accordion minimized. Touch-friendly 52px button heights. |
| Tablet | Centered modal card (400px wide). Same layout as mobile but floating. |
| Desktop | Centered modal card (400px wide). Backdrop click to dismiss. Keyboard focus trapped within modal for accessibility. ESC key closes modal. |
