# 04.1 Listing Editor

**Scenario:** 04: Lan Lists Her Business
**Page Number:** 04.1
**Created:** 2026-04-07
**Updated:** 2026-04-08
**Method:** Whiteport Design Studio (WDS)

---

## Overview

**Page Purpose:** Create a business listing with photos, basic info, and auto-translated menu — get visible to Japanese customers in under 15 minutes.

**Entry Points:**
- Zalo link from DaNangNavi rep (primary)
- Business portal dashboard → "Tạo tin đăng" (Create Listing)
- Post-registration redirect

**User Mental State:**
- **Trigger:** Competitor got listed, Japanese customers mentioned DaNangNavi. Quiet Tuesday afternoon — now or never.
- **Hope:** "Maybe this can bring in the Japanese tourists who walk past every day but never come in."
- **Worry:** "I don't speak Japanese and I'm not tech-savvy. If this takes more than 15 minutes, I'm closing it."

**Main User Goal:** Publish a complete business listing with photos and translated menu in under 15 minutes, entirely in Vietnamese.

**Business Goal:** Onboard one more business toward the 300 target, with quality listing content that attracts Japanese users.

**URL/Route:** `/business/listings/new`

---

**Next Page:** Coupon Manager (04.2)

**Scenario Goal:** Lan creates a listing, adds a coupon, and sees her dashboard — all in a Vietnamese UI she can understand.

### Section 1: Progress Header

| Element | Detail |
|---------|--------|
| Page title | "Tạo tin đăng mới" (Create New Listing) — `text-h2` (24px, Bold) |
| Step indicator | 3 steps: "① Thông tin · ② Ảnh & Menu · ③ Xem trước" — horizontal, active step = `color-primary` (#1B2A4A), completed = `color-success` (#27AE60), upcoming = `color-text-secondary` |
| Step connector | Thin line between step circles |

**Design Rationale:** 3-step progress bar answers "how long will this take?" immediately. Time estimate reassures Lan she won't be stuck for hours. Vietnamese-only UI — no Japanese anywhere on this page.

### Section 2: Step 1 — Basic Information Form

**Layout:** Vertical form with labeled fields, all in Vietnamese

| # | Field | Type | Properties |
|---|-------|------|------------|
| 1 | Tên doanh nghiệp (Business name) | Text input | Required, placeholder: "VD: Quán Phở Hương" |
| 2 | Danh mục (Category) | Dropdown select | Required, options: Nhà hàng, Quán cà phê, Spa, Khách sạn, Tour, Dịch vụ khác |
| 3 | Địa chỉ (Address) | Text input + map pin | Required, auto-suggest via Google Places API |
| 4 | Số điện thoại (Phone) | Phone input | Required, pre-filled from account if available |
| 5 | Giờ mở cửa (Opening hours) | Time selector | Required, quick presets: "8:00-22:00" / "10:00-21:00" / Tùy chỉnh |
| 6 | Mô tả ngắn (Short description) | Textarea | Optional, max 200 chars, placeholder: "Mô tả ngắn về doanh nghiệp..." |
| 7 | Zalo liên hệ (Zalo contact) | Text input | Optional, placeholder: "Số Zalo hoặc link" |

**Form Properties:**

| Property | Value |
|----------|-------|
| Label font | `text-caption` (14px, SemiBold) |
| Input height | 48px (touch-friendly) |
| Input background | `color-surface` (#FFFFFF) |
| Input border | 1px solid `#E5E7EB`, focus: 2px `color-accent` (#2EC4B6) |
| Input border radius | `radius-sm` (8px) |
| Required indicator | Red asterisk (*) after label |
| Error state | Red border + error message below field in Vietnamese |
| Field spacing | `space-xl` (24px) between fields |

**Design Rationale:** Familiar form pattern, all Vietnamese. Category dropdown limits choices to prevent confusion. Address auto-suggest reduces typing on mobile. Opening hours presets save time for common schedules.

### Section 3: Step 2 — Photos & Menu Upload

**Layout:** Photo grid + menu OCR section

#### Photos Sub-section

| Element | Detail |
|---------|--------|
| Section label | "Ảnh doanh nghiệp" (Business Photos) — `text-h3` |
| Instruction | "Thêm ít nhất 3 ảnh. Ảnh đầu tiên sẽ là ảnh bìa." — `text-caption`, `color-text-secondary` |

| Photo actions | Tap uploaded photo → preview, reorder drag handle, "×" to remove |
| Max photos | 10 photos |
| Source | Device camera roll (opens native picker) |

#### Menu OCR Sub-section

| Element | Detail |
|---------|--------|
| Section label | "Menu / Thực đơn" — `text-h3` |
| Upload trigger | "📷 Chụp ảnh thực đơn" (Photograph your menu) — `primary-cta-button` (compact), outline style |
| Processing state | Spinner + "Đang nhận dạng menu..." (Recognizing menu...) — 3-5 seconds |
| OCR result | Editable table: Vietnamese dish name (auto-detected) → Japanese translation (auto-generated) |
| Edit capability | Tap any cell to correct OCR errors |
| Confidence indicator | Green check (high confidence) / Yellow warning (review suggested) per row |
| Add row | "＋ Thêm món" (Add dish) — text link at bottom of table |

**OCR Result Table:**

| Món ăn (Dish - VI) | Dịch sang tiếng Nhật (JP Translation) | Giá (Price) | Confidence |
|---------------------|---------------------------------------|-------------|------------|
| Bún chả | ブンチャー | 50,000₫ | ✅ |
| Phở bò | フォーボー（牛肉のフォー） | 45,000₫ | ✅ |
| Gỏi cuốn | ゴイクオン（生春巻き） | 30,000₫ | ⚠️ |

**Design Rationale:** Menu OCR is the magic moment — Lan photographs her paper menu and sees Japanese translations appear. This is the core value proposition for business owners: "we translate for you." Editable table lets her correct mistakes. Confidence indicators build trust in the automation.
