## Overview

**Page Purpose:** Read and participate in a discussion thread, post own question about weekend activities in Da Nang.

**Entry Points:**
- Tap on a trending thread from Community Hub (02.1)
- Push notification linking to a thread with new replies
- Direct link shared in LINE group

**User Mental State:**
- **Trigger:** Saw an active discussion "Best weekend spots for solo expats?" and clicked in
- **Hope:** "Maybe someone else is in my exact situation — I can ask my own question and get real answers"
- **Worry:** "Will I look stupid asking such a basic question? Will anyone actually reply?"

**Main User Goal:** Read helpful replies from experienced expats, then post his own question about weekend activities and feel confident it will get answered.

**Business Goal:** Generate UGC engagement — new thread creation, replies, upvotes — driving toward 10K comments/day target.

**URL/Route:** `/community/thread/:threadId`

## Design Sections

### Section 1: Thread Header — Original Post

**Layout:** Full-width card with original poster info and question body

| Element | Detail |
|---------|--------|
| OP avatar | 40px circle, user photo or default avatar |
| OP name | Username + "先輩" (Senpai) badge if earned |
| Post date | Relative time: "3時間前" (3 hours ago) |
| Thread title | "週末、一人で行ける場所ありますか？" (Any places to go alone on weekends?) |
| Thread body | Full question text with context — mentions being new, looking for cafes, parks, or activity spots |
| Tags | Pill chips: #週末 (Weekend), #一人暮らし (Solo life), #おすすめ (Recommendations) |
| Engagement stats | 💬 12件の返信 (12 replies) · ❤️ 23 いいね (23 likes) |

**Design Rationale:** Thread title and body are prominent to validate Naoki's situation — seeing someone else ask the same question normalizes his experience. Senpai badge on respondents builds trust in the advice.

### Section 2: Reply List

**Layout:** Vertical stack of reply cards, sorted by most helpful (upvotes) by default

| Element | Detail |
|---------|--------|
| Reply avatar | 36px circle with user photo |
| Reply name | Username display, bold |
| Senpai badge | Teal (#2EC4B6) badge "先輩" next to name if user has senpai status |
| Reply text | Full reply content, supports line breaks and links |
| Inline photo | Optional attached photo (thumbnail, tap to expand) |
| Upvote button | ▲ count — tap to upvote, coral (#FF6B4A) when active |
| Reply timestamp | Relative: "2時間前" (2 hours ago) |
| Reply action | "返信する" (Reply) link for nested replies |
| Sort toggle | Top of list: "人気順" (Popular) / "新着順" (Newest) pills |

**Sample Replies:**

| Replier | Badge | Content Preview |
|---------|-------|-----------------|
| TakeshiDN | 先輩 | "My Khe Beach is great on Saturday mornings. Also check out the events page — there's a BBQ this Saturday!" |
| YukiCafe | 先輩 | "Son Tra peninsula hike is amazing solo. I go every other Sunday." |
| MaikoNewbie | — | "I'm also new! Following this thread. Let's hang out sometime?" |

**Design Rationale:** Senpai-badged replies float to top, establishing credibility hierarchy. Mix of senpai and newcomer replies shows Naoki he is not alone — others are in the same boat. The BBQ event mention creates a natural bridge to Events page (02.3).

### Section 3: Reply Composer

**Layout:** Sticky bottom bar that expands on tap into a full composer

| Element | Detail |
|---------|--------|
| Collapsed state | Single-line input: "返信を書く..." (Write a reply...) with avatar thumbnail |
| Expanded state | Multi-line text area (auto-grow to 5 lines max before scroll) |
| Photo upload | Camera icon button — attach up to 3 photos |
| Submit button | "投稿する" (Post) — Coral (#FF6B4A) filled button, disabled until text entered |
| Character count | Subtle gray counter: "0/500" |
| Cancel action | "×" to collapse back to single line |

**Design Rationale:** Sticky composer keeps participation friction low — always visible, one tap to start writing. Low character limit (500) encourages concise, helpful replies rather than essays. Photo support lets users share location screenshots or recommendations visually.
