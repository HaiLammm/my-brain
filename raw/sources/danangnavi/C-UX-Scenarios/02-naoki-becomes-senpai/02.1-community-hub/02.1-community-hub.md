## Overview

**Page Purpose:** Browse community groups, active discussions, and upcoming events — discover that there's a vibrant Japanese expat community in Da Nang.

**Entry Points:**
- Tap "コミュニティ" tab in bottom navigation (primary)
- Push notification about new community activity
- Deep link from homepage community highlights section (01.1)

**User Mental State:**
- **Trigger:** Sunday afternoon, apartment feels empty. Colleagues are with families. Opens DaNangNavi and sees notification badge on Community tab.
- **Hope:** "Maybe there are other Japanese people here who feel the same way — I want to find my people."
- **Worry:** "What if it's dead? Just another empty forum with posts from 6 months ago."

**Main User Goal:** Discover an active Japanese expat community and find a specific discussion or event worth engaging with.

**Business Goal:** Drive community discovery → thread views → first post/reply, moving Naoki toward the 500 active senpai target.

**URL/Route:** `/community`

## Design Sections

### Section 1: Community Header

**Layout:** Full-width header with page title and activity summary

| Element | Detail |
|---------|--------|
| Page title | "コミュニティ" (Community) — `text-h1` (32px, Bold) |
| Activity pulse | "今日のアクティビティ: 47件の投稿 · 156件の返信" (Today: 47 posts · 156 replies) — `text-caption`, `color-accent` (#2EC4B6) |
| New post button | "＋ 投稿する" (New Post) — `primary-cta-button` (compact), top-right |

**Design Rationale:** Activity pulse immediately answers Naoki's worry — "is this dead?" Large numbers prove the community is alive. New post button is visible but not the primary action — browsing first, posting later.

## Responsive Behavior

| Breakpoint | Changes |
|------------|---------|
| Mobile (< 768px) | Single column, horizontal scroll for categories and events, sticky bottom tab nav |
| Tablet (768-1024px) | 2-column grid for categories, events in wider cards, top nav replaces bottom tab |
| Desktop (> 1024px) | 3-column layout: categories sidebar (left, 20%), threads (center, 50%), events + activity (right, 30%), sticky top nav |

## On-Page Interactions

| Interaction | Type | Detail |
|-------------|------|--------|
| Category card tap | Navigation | Filters thread list to that category |
| Thread card tap | Navigation | Goes to thread detail page (02.2) — **primary exit action** |
| "すべて見る →" (threads) | Navigation | Goes to full thread listing with filters |
| Event card tap | Navigation | Goes to event detail on Events page (02.3) |
| "すべて見る →" (events) | Navigation | Goes to Events & Meetups page (02.3) |
| "＋ 投稿する" tap | Navigation/Modal | Opens new thread composer (full page or modal) |
| Activity item tap | Navigation | Goes to referenced thread, member, or event |
| "もっと見る" tap | On-page | Loads more activity items |
| Pull to refresh | On-page | Refreshes all sections with latest data |
