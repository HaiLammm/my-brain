## Overview

**Page Purpose:** Discover upcoming Japanese expat events and sign up for a BBQ meetup this Saturday — take the step from online community to real-life connection.

**Entry Points:**
- Tap on event link mentioned in a community thread reply (02.2)
- Bottom tab nav or community hub events section
- Push notification about upcoming events near user

**User Mental State:**
- **Trigger:** A senpai in the thread mentioned a BBQ this Saturday — Naoki clicked the events link
- **Hope:** "I can actually meet people this weekend — this BBQ sounds perfect for someone like me"
- **Worry:** "What if I show up and don't know anyone? Will it be awkward?"

**Main User Goal:** Find the BBQ meetup event, see who else is going, and sign up with confidence.

**Business Goal:** Convert online community engagement into offline meetup attendance — key step toward building the 500 active senpai community.

**URL/Route:** `/events`

## Design Sections

### Section 1: Page Header + View Toggle

**Layout:** Top bar with page title and calendar/list toggle

| Element | Detail |
|---------|--------|
| Page title | "イベント＆ミートアップ" (Events & Meetups) |
| View toggle | Two-button pill toggle: "リスト" (List) / "カレンダー" (Calendar) — default: List |
| List view | Vertical stack of event cards, grouped by date |
| Calendar view | Monthly grid with dot indicators on event dates, tap date to see events below |

**Design Rationale:** List view is default because it is more scannable on mobile and shows event details at a glance. Calendar view serves power users who want to plan ahead. Toggle is familiar pattern from Japanese calendar apps.

---

### Section 2: Filter Chips

**Layout:** Horizontal scrollable chip row below header

| Chip | Japanese | English | Behavior |
|------|----------|---------|----------|
| 今週 | 今週 | This week | Filters to current week events |
| 週末 | 週末 | Weekend | Filters to Saturday/Sunday events |
| 食事会 | 食事会 | Dinner | Filters to food/dining events |
| アウトドア | アウトドア | Outdoor | Filters to outdoor activities |
| 交流会 | 交流会 | Social meetup | Filters to networking/social events |
| 初心者歓迎 | 初心者歓迎 | Newcomers welcome | Filters to beginner-friendly events |

**Design Rationale:** "初心者歓迎" (Newcomers welcome) chip directly addresses Naoki's worry about fitting in. Chip selection is multi-select with coral (#FF6B4A) filled state. "週末" is pre-selected given Naoki's context.

### Section 3: Event Cards (List View)

| Element | Detail |

| Date/time | Icon + text: "📅 4月12日（土）16:00〜20:00" |
| Location | Icon + text: "📍 My Khe Beach エリア" with map pin link |

| CTA button | "参加する" (Join) — Coral (#FF6B4A) filled, full width |
| Price | "無料" (Free) or "¥500〜" — shown near CTA |

**Sample Event Cards:**

| Event | Date | Attendees | Host |

| 日本人BBQミートアップ | 4月12日（土）16:00 | 12人 | TakeshiDN (先輩) |

### Section 4: Event Detail (Expanded View)

**Layout:** Full-screen overlay or dedicated page when an event card is tapped

| Element | Detail |
|---------|--------|
| Hero photo | Full-width event photo, 3:2 ratio |
| Title | Large, bold: "日本人BBQミートアップ🔥" |
| Date/time | "4月12日（土）16:00〜20:00" |
| Location | "My Khe Beach BBQエリア" with embedded mini-map (tap to open full map) |
| Description | Multi-paragraph event description in Japanese: what to expect, what to bring, who's hosting |
| Host section | Host avatar + name + senpai badge + brief bio: "ダナン在住2年。毎月BBQやってます！" (2 years in Da Nang. Monthly BBQ organizer!) |
| Attendee list | Scrollable avatar row with names, tap to view profile. "12人参加予定" header |
| Newcomer note | Highlighted box: "初めての方も大歓迎！気軽に来てください 😊" (First-timers very welcome! Come casually) |
| Join button | Large sticky bottom CTA: "参加する" (Join) — Coral (#FF6B4A) |
| Share button | Share icon — copies event link or opens share sheet |
| Add to calendar | "カレンダーに追加" — exports .ics or opens device calendar |

**Design Rationale:** The newcomer note and host bio are critical for Naoki — they explicitly address his anxiety about showing up alone. Attendee list shows real faces, making the event feel safe and social. Sticky join button ensures CTA is always reachable.

### Section 5: Post-Join Confirmation

**Layout:** Modal overlay after tapping "参加する"

| Element | Detail |
|---------|--------|
| Success icon | Checkmark animation (teal) |
| Headline | "参加登録完了！🎉" (Registration complete!) |
| Subtext | "4月12日（土）のBBQミートアップに参加します" (You're joining the BBQ Meetup on Saturday April 12) |
| Reminder option | Toggle: "リマインダーを受け取る" (Receive reminder) — default ON |
| Action buttons | "マイページで確認 →" (Check in My Page) / "閉じる" (Close) |

**Design Rationale:** Confirmation modal provides immediate positive feedback. Reminder toggle reduces no-show risk. "Check in My Page" CTA naturally bridges to User Profile (02.4), the next page in this scenario.

## Responsive Behavior

| Breakpoint | Changes |
|------------|---------|
| Mobile (< 768px) | Single column card stack, full-width event cards, bottom tab nav, event detail as full-screen overlay |
| Tablet (768-1024px) | Two-column card grid, event detail as side panel, top nav appears |
| Desktop (> 1024px) | Three-column card grid, event detail opens in right panel (60/40 split), calendar view shows full month grid, sticky top nav, no bottom tab |
