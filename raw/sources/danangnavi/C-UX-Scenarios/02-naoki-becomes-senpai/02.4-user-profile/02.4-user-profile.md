# 02.4 User Profile

**Scenario:** 02: Naoki Becomes Senpai
**Page Number:** 02.4
**Created:** 2026-04-07
**Method:** Whiteport Design Studio (WDS)

---

## Overview

**Page Purpose:** View personal activity history and senpai progress tracker — see the journey from newcomer to senpai, and feel motivated to keep contributing to the community.

**Entry Points:**
- Tap "マイページで確認" from event join confirmation (02.3)
- Bottom tab nav "マイページ" (Profile)
- Tap own avatar anywhere in the app

**User Mental State:**
- **Trigger:** Just signed up for the BBQ meetup, tapped "Check in My Page" from the confirmation
- **Hope:** "I'm actually doing this — I'm becoming part of the community. I wonder how far I've come"
- **Worry:** "I'm still a newcomer... will I ever be seen as someone who belongs here?"

**Main User Goal:** See his activity history (thread, event signup) reflected on his profile and understand the path from newcomer to senpai.

**Business Goal:** Gamified senpai progression drives sustained engagement — users who see progress are more likely to continue contributing, building toward the 500 active senpai target.

**URL/Route:** `/profile` or `/profile/:userId`

---

## Journey Context

This is **page 4 of 4** (final page) in the "Naoki Becomes Senpai" scenario.

**Previous Page:** Events & Meetups (02.3)

**Scenario Goal:** Naoki joins the Japanese expat community and begins his transformation from lonely newcomer to active community member.

**Scenario Success Criteria:** Naoki sees his "Newcomer" status and the clear path to becoming senpai — he feels motivated to continue participating. The lonely Sunday afternoon has become the start of a new chapter.

## Design Sections

### Section 1: Profile Header

**Layout:** Full-width header card with avatar and key stats

| Element | Detail |
|---------|--------|
| Avatar | 80px circle, user photo (or default silhouette with edit icon) |
| Display name | Bold, Navy (#1B2A4A): "Naoki" |
| Status badge | Current rank pill: "ニューカマー" (Newcomer) — gray/silver badge |
| Member since | "📅 2026年3月から" (Since March 2026) |
| Location | "📍 ダナン" (Da Nang) |
| Bio | Editable one-liner: "ダナン在住3週間目のエンジニアです" (Engineer, 3 weeks in Da Nang) |
| Edit button | "プロフィール編集" (Edit Profile) — ghost button, top right |
| Stats row | Three columns: "投稿 2" (Posts) | "参加イベント 1" (Events joined) | "いいね 5" (Likes received) |

**Design Rationale:** Stats row provides instant gratification — Naoki sees his activity already reflected (the thread post and BBQ signup). Low numbers feel honest rather than empty, and the senpai progress section below shows how these grow.

### Section 2: Senpai Progress Tracker

**Layout:** Visual progress section with milestone bar and checklist

| Element | Detail |
|---------|--------|
| Section title | "先輩への道" (Path to Senpai) |
| Progress bar | Horizontal bar divided into 4 stages, current stage highlighted |
| Stage 1 | "ニューカマー" (Newcomer) — Active, teal (#2EC4B6) filled |
| Stage 2 | "アクティブメンバー" (Active Member) — Gray, locked |
| Stage 3 | "コントリビューター" (Contributor) — Gray, locked |
| Stage 4 | "先輩" (Senpai) — Gray, locked, with star icon |
| Current label | "現在のステータス: ニューカマー" (Current status: Newcomer) |
| Next milestone | "次のステップ: アクティブメンバー" (Next step: Active Member) |

**Milestone Checklist for Active Member:**

| Milestone | Status | Detail |
|-----------|--------|--------|
| 初めての投稿 | ✅ Complete | First post in community |
| 3件の返信を投稿 | 🔲 0/3 | Post 3 replies |
| イベントに参加 | ✅ Complete | Attend an event |
| プロフィール写真を設定 | 🔲 Not done | Set a profile photo |
| 5件のいいねを獲得 | ✅ Complete | Receive 5 likes |

**Design Rationale:** This is the scenario success moment. Naoki sees he has already completed 3 of 5 milestones for the next rank just from today's activity. The progress bar makes the senpai journey feel achievable, not distant. Checklist items are specific and actionable — he knows exactly what to do next. Teal color on completed items matches the platform's positive-action color.

## Responsive Behavior

| Breakpoint | Changes |
|------------|---------|
| Mobile (< 768px) | Single column, full-width sections stacked vertically, saved content as horizontal scroll, bottom tab nav |
| Tablet (768-1024px) | Two-column layout: profile header + progress (left), activity + saved (right), top nav appears |
| Desktop (> 1024px) | Three-column layout: profile sidebar (left, 25%), progress + activity (center, 50%), saved + settings (right, 25%), sticky top nav, no bottom tab |

## On-Page Interactions

| Interaction | Type | Detail |
|-------------|------|--------|
| Edit profile tap | Navigation | Opens profile edit form (name, bio, avatar upload) |
| Progress stage tap | On-page | Shows tooltip with requirements for that stage |
| Milestone item tap | On-page | Incomplete items show hint: e.g., "返信を3件投稿しましょう" (Post 3 replies) |
| Activity card tap | Navigation | Goes to the referenced content (thread, event, etc.) |
| Saved content card tap | Navigation | Goes to that listing, guide, or thread |
| "View all" saved tap | Navigation | Goes to full saved content page |
| Settings link tap | Navigation | Goes to settings page |
| Stats number tap | Navigation | Goes to filtered view (e.g., tap "Posts 2" to see own posts) |
| Avatar tap | On-page | Opens photo picker to update profile photo |
