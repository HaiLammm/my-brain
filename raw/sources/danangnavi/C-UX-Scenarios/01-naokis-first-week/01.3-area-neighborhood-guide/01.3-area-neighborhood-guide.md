# 01.3 Area / Neighborhood Guide

**Scenario:** 01: Naoki's First Week
**Page Number:** 01.3
**Created:** 2026-04-07
**Method:** Whiteport Design Studio (WDS)

## Overview

**Page Purpose:** Help Naoki decide which neighborhood to live in based on commute, lifestyle, price range, and senpai recommendations.

**Entry Points:**
- Onboarding checklist "住むエリアを決める" link (primary)
- Homepage category "住まい" quick link
- Search results "エリアガイド" filter
- Direct URL /areas/[area-slug]

**User Mental State:**
- **Trigger:** Completed onboarding, checklist says "decide your area first"
- **Hope:** "I want to find the neighborhood that's perfect for my situation — near work, good food, reasonable rent"
- **Worry:** "What if I pick the wrong area and end up with a long commute or in an unsafe neighborhood?"

**Main User Goal:** Compare 2-3 neighborhoods and choose the best one for my office location, budget, and lifestyle

**Business Goal:** Guide users to area-specific content, increase page depth (3+ pages per session), establish DaNangNavi as the authoritative neighborhood resource

**URL/Route:** `/areas` (index) and `/areas/[slug]` (detail)

### Section 2: Area Comparison Cards

**Layout:** Vertical card stack (mobile) / 2-column grid (desktop)

**Each Area Card contains:**

| Element | Detail |
|---------|--------|
| Photo | Area hero image (street scene, landmark) |
| Name | e.g., "ソンチャ（Son Tra）" |
| Tagline | "ビーチ近くで静かな暮らし" (Quiet living near the beach) |
| Commute | "🚗 職場まで15分" (15 min to workplace) — personalized if workplace set |
| Rent range | "🏠 6-10百万VND/月（¥36,000-60,000）" — dual currency |
| Senpai count | "👥 先輩 42人が在住" (42 senpai live here) |
| Rating | ⭐ 4.5 — senpai satisfaction rating |
| Highlights | 3 tags: "静か" (Quiet), "ビーチ" (Beach), "日本食多い" (Many Japanese restaurants) |
| CTA | "詳しく見る →" (Learn more) |

**Areas to Display:**
1. ハイチャウ (Hai Chau) — Central, walkable, most amenities
2. ソンチャ (Son Tra) — Beach, quiet, expat-popular
3. ゴバンハン (Ngu Hanh Son) — My Khe Beach area, tourist zone
4. ハン川東エリア (East of Han River) — Local, affordable, authentic
