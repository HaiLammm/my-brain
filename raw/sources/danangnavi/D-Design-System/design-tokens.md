# DaNangNavi Design Tokens

> Single source of truth for all shared design values across the platform.

---

## Color Tokens

### Brand Colors

| Token | Value | Usage |
|-------|-------|-------|
| `color-primary` | `#1B2A4A` (Navy) | Headers, nav, primary text, brand identity |
| `color-secondary` | `#FF6B4A` (Coral) | CTAs, highlights, deals, accent |
| `color-accent` | `#2EC4B6` (Teal) | Links, tags, secondary actions, badges |

### Surface Colors

| Token | Value | Usage |
|-------|-------|-------|
| `color-bg` | `#FAFAF8` (Warm White) | Page background |
| `color-surface` | `#FFFFFF` (White) | Cards, modals, sheets |
| `color-surface-hover` | `#F5F5F3` | Card hover state |

### Text Colors

| Token | Value | Usage |
|-------|-------|-------|
| `color-text-primary` | `#0D1B2A` (Dark Navy) | Body text, headings |
| `color-text-secondary` | `#6B7280` (Gray) | Captions, metadata, timestamps |
| `color-text-inverse` | `#FFFFFF` (White) | Text on dark/colored backgrounds |
| `color-text-link` | `#2EC4B6` (Teal) | Inline links |

### Status Colors

| Token | Value | Usage |
|-------|-------|-------|
| `color-success` | `#27AE60` (Green) | Confirmations, verified, fair price |
| `color-warning` | `#F2994A` (Amber) | Alerts, slightly high price |
| `color-error` | `#EB5757` (Red) | Errors, caution price, destructive |
| `color-info` | `#2EC4B6` (Teal) | Info badges, tips |

## Typography Tokens

### Font Family

| Token | Value |
|-------|-------|
| `font-family-primary` | `'Noto Sans JP', sans-serif` |
| `font-family-ui` | `'Inter', 'Noto Sans', sans-serif` |

| Token | Size | Weight | Line Height | Usage |
|-------|------|--------|-------------|-------|
| `text-h1` | 32px | Bold (700) | 1.3 | Page titles |
| `text-h2` | 24px | Bold (700) | 1.4 | Section headings |
| `text-h3` | 20px | SemiBold (600) | 1.4 | Subsection headings |
| `text-body` | 16px | Regular (400) | 1.6 | Body text |
| `text-caption` | 14px | Regular (400) | 1.5 | Captions, metadata |
| `text-small` | 12px | Regular (400) | 1.5 | Labels, badges |
