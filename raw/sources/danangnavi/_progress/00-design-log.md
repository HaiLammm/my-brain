## Key Decisions

| Date | Decision | Rationale |
|------|----------|-----------|
| 2026-04-06 | B2B2C model: free for users, paid for businesses | Build user base first, monetize after proving value |
| 2026-04-06 | Next.js + Tailwind for demo | Fastest path for solo developer with 7-day deadline |
| 2026-04-07 | 3 target groups (not 4) | Retiree deferred to Phase 2 per Product Brief |
| 2026-04-07 | Senpai community as PRIMARY goal | Network effect is the competitive moat |
| 2026-04-07 | Language tools as platform foundation | Cross-group research confirms #1 barrier |
| 2026-04-07 | 5 scenarios (not 3) covering all 17 pages | Small scale (<20 pages) enables comprehensive coverage without selective ignorance |
| 2026-04-07 | Naoki gets 2 Priority 1 scenarios (settlement + community) | His full arc from newcomer to senpai IS the flywheel — can't be captured in one scenario |
| 2026-04-07 | Suggest mode for all scenarios | User approved AI-proposed scenarios based on Trigger Map data — efficient for well-documented project |
| 2026-04-07 | Dream Up mode for all page specs | All 5 scenarios used autonomous design — user trusts Trigger Map data is sufficient for AI-driven specs |
| 2026-04-07 | Dual-language UI: Japanese (users) + Vietnamese (business) | Lan's dashboard uses Vietnamese natively, not translated Japanese — respects her actual language |
| 2026-04-07 | Bottom tab nav (5 tabs): Home, Search, Community, Deals, Profile | Familiar Japanese mobile pattern (LINE/Naver), covers core user needs |
| 2026-04-07 | Fair-price indicators on all listings | Directly addresses Naoki's and Tomoko's #1 fear — being overcharged as foreigners |
